Sebelum pakai AI
Agent bakal baca kode proyek ini Claude Code bakal baca kode di folder aplikasi-a dan ngirimnya ke provider-nya buat nulis flow. Jagra sendiri nggak ngirim apa pun. Kalau ini aplikasi kantor, pastiin aturan kantor ngizinin.

Peringatan perubahan file

Muncul setelah agent selesai kalau ada file di luar folder flow yang berubah. Tombol utama Kembalikan.

Layar 1 sampai 8 itu alur utama: dari cek lingkungan sampai bikin flow dengan AI. Layar 9 sampai 14 itu layar pendukung dan jendela kecil yang muncul di kondisi tertentu. Isi di dalam layar (nama file, angka, teks error) cuma contoh buat ngebayangin. Versi 1 belum punya build dari folder.
