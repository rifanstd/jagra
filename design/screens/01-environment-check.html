Cek lingkungan

Jagra memakai tool yang sudah terpasang di komputer ini. Jagra tidak memasang, memperbarui, atau menghapus apa pun.

Wajib

Selesai dalam 2,1 detik Memeriksa semua tool sekaligus
  • Java 17 atau lebih baru C:\Program Files\Java\jdk-17\bin\java.exe 17.0.12 ✓Siap Memeriksa
  • Android platform tools (adb) C:\Users\rfan\AppData\Local\Android\Sdk\platform-tools\adb.exe 37.0.0 ✓Siap Memeriksa
  • Maestro C:\maestro\bin\maestro.bat 2.12.1 ✓Siap Memeriksa
  • Maestro ✕Tidak ditemukan

    Maestro yang menjalankan setiap flow, jadi run belum bisa dimulai. Cara memasangnya di Windows:

    1. Unduh maestro.zip dari halaman rilis Maestro di GitHub.
    2. Ekstrak ke folder tetap, misalnya C:\maestro.
    3. Tambahkan C:\maestro\bin ke variabel PATH di Environment Variables Windows.
    4. Kembali ke sini dan tekan Cek ulang. Jagra tidak perlu ditutup.

    Panduan resmi Maestro · Sudah terpasang di folder lain? Atur lokasinya
